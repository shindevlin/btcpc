btcpctest nodes

Real devices can run the separate BTCPCTEST chain, earn BTCPCTEST as the native testnet token, and also collect a small BTCPC bonus. By default the testnet is report-only: clocks keep time, nodes report their roles, and real inference/storage work stays off unless developers enable it for allowlisted usernames through network policy. Read the spec.

BTCPCTEST → separate testnet token
BTCPC bonus → keep the network honest
report-only → default testnet mode
status → /public/testnet/access
